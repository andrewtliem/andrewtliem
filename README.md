### 🧭 Research & Focus
I sit at the intersection of **Computer Science Education**, **AI Agentic Systems**, and **Intelligent Optical Networks**.

My current work focuses on building **autonomous agents** that can reason through complex workflows—whether that's analyzing optical telemetry in EPON networks or providing structured feedback on academic papers.

- 🔭 **Current Focus**: Multi-agent workflows, Optical Network Digital Twins, Telemetry Analysis.
- 🧪 **Research**: Intelligent Network Management, QoT/QoS Modeling, IEEE Heuristic Classification.
- 🎓 **Teaching**: System Analysis and Design, MIS, Computer Networks, Computational Thinking.

### ⚡ Agentic Workflows & Projects

#### 📡 **1. Network Agent (EPON/Optical)**
An intelligent agent designed for network observability and management.
- **Capabilities:** Parses optical telemetry, performs IEEE-style heuristic classification, and interprets QoT (Quality of Transmission) anomalies.
- **Stack:** Python, FastAPI, Structured LLM Outputs.

#### 📝 **2. Reviewer Agent (Academic)**
A specialized agent for automating academic feedback loops.
- **Capabilities:** conducting rubric-based scoring, providing structured reasoning for grades, and suggesting specific revisions.
- **Stack:** Python, Supabase, OpenAI API.

#### 🎓 **3. Classroom Assistant**
- **Capabilities:** Generates study guides, self-evaluations, and rubric-aligned analytics for students.
- **Stack:** Next.js, Supabase Auth.
